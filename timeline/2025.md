# 2025 Timeline

This file includes 14 notable incidents, disclosures, and vulnerability-driven milestones relevant to LLM security in 2025.

## Entries

### 27. January 2025: Cross-tenant memory leakage reviews expanded in enterprise copilots

- **Category:** Multi-tenant isolation
- **Class:** Security review trend
- **Summary:** Enterprise reviews increasingly focused on whether one user's context, memory, or retrieved state could influence another user's session.
- **CVE:** None public
- **Lesson:** Memory and retrieval state need tenant boundaries as strict as primary data stores.

### 28. February 2025: Agentic browser automation token theft scenarios gained traction

- **Category:** Agent security
- **Class:** Red-team pattern
- **Summary:** Browser-using agents were shown to risk exposing session tokens or executing attacker-shaped workflows across web contexts.
- **CVE:** None public
- **Lesson:** Browser agents require origin controls, secret isolation, and high-friction approvals.

### 29. March 2025: vLLM distributed runtime XPUB issue disclosed

- **Category:** Inference serving security
- **Class:** CVE-backed vulnerability
- **Summary:** A vLLM issue showed how distributed serving features could expose systems to denial-of-service or unintended runtime effects.
- **CVE:** [CVE-2025-30202](https://nvd.nist.gov/vuln/detail/CVE-2025-30202)
- **Lesson:** Inference engines deserve the same protocol hardening as distributed application middleware.

### 30. April 2025: Open WebUI stored XSS enabled account takeover and possible RCE chains

- **Category:** Self-hosted AI platform security
- **Class:** CVE-backed vulnerability
- **Summary:** Malicious chat content could execute JavaScript in user browsers, steal tokens, and potentially pivot into administrative compromise.
- **CVE:** [CVE-2025-46719](https://nvd.nist.gov/vuln/detail/CVE-2025-46719)
- **Lesson:** Chat transcripts are active attack surfaces when rendered HTML is not tightly controlled.

### 31. May 2025: Enterprise RAG poisoning incidents became a top design concern

- **Category:** RAG poisoning
- **Class:** Operational trend
- **Summary:** Security teams documented repeated attempts to influence internal assistants by seeding manipulated content into indexed corpora.
- **CVE:** None public
- **Lesson:** Indexing pipelines need provenance, review, and abuse monitoring.

### 32. June 2025: vLLM prompt embedding corruption and request handling issues surfaced

- **Category:** Inference integrity
- **Class:** CVE-backed vulnerability
- **Summary:** Serving-layer flaws highlighted how malformed or adversarial requests could impact model serving correctness or stability.
- **CVE:** [CVE-2025-62164](https://nvd.nist.gov/vuln/detail/CVE-2025-62164)
- **Lesson:** Even non-RCE inference bugs can undermine reliability and trust.

### 33. July 2025: Open WebUI prompt insertion DOM XSS disclosure

- **Category:** Platform abuse
- **Class:** CVE-backed vulnerability
- **Summary:** Rendered prompt content in the UI could become an execution vector in the browser when insufficiently sanitized.
- **CVE:** [CVE-2025-64495](https://nvd.nist.gov/vuln/detail/CVE-2025-64495)
- **Lesson:** Prompt and transcript rendering is a frontend security problem, not just an AI problem.

### 34. July 2025: Open WebUI direct connection code injection issue disclosed

- **Category:** Self-hosted platform security
- **Class:** CVE-backed vulnerability
- **Summary:** Direct connection and integration features in self-hosted AI tooling created avenues for code injection or privileged misuse.
- **CVE:** [CVE-2025-64496](https://nvd.nist.gov/vuln/detail/CVE-2025-64496)
- **Lesson:** Convenience integrations often become privilege escalation surfaces.

### 35. August 2025: Open WebUI authentication and configuration weaknesses continued to surface

- **Category:** Platform hardening
- **Class:** CVE-backed vulnerability
- **Summary:** Additional disclosures showed that auth and config handling remained a meaningful risk in fast-moving self-hosted AI platforms.
- **CVE:** [CVE-2025-63391](https://nvd.nist.gov/vuln/detail/CVE-2025-63391)
- **Lesson:** Self-hosted AI frontends need disciplined release engineering and security review.

### 36. September 2025: vLLM API key timing attack issue disclosed

- **Category:** Authentication security
- **Class:** CVE-backed vulnerability
- **Summary:** Built-in API key comparison logic exposed inference services to timing-based credential recovery in certain deployments.
- **CVE:** [CVE-2025-59425](https://nvd.nist.gov/vuln/detail/CVE-2025-59425)
- **Lesson:** Authentication code in AI-serving software is still security-critical auth code.

### 37. October 2025: Open WebUI SSRF disclosure

- **Category:** Connector and network security
- **Class:** CVE-backed vulnerability
- **Summary:** Server-side request forgery paths showed how connector-heavy AI apps can be abused to reach internal services.
- **CVE:** [CVE-2025-65958](https://nvd.nist.gov/vuln/detail/CVE-2025-65958)
- **Lesson:** Connector features need strict egress policy and destination validation.

### 38. October 2025: Open WebUI note and PDF rendering XSS issue disclosed

- **Category:** Document handling security
- **Class:** CVE-backed vulnerability
- **Summary:** Uploaded or rendered note content introduced another path for browser-side compromise in self-hosted AI interfaces.
- **CVE:** [CVE-2025-65959](https://nvd.nist.gov/vuln/detail/CVE-2025-65959)
- **Lesson:** File and note rendering in AI apps requires the same sanitization rigor as any rich document platform.

### 39. November 2025: LangChain serialization injection vulnerability disclosed

- **Category:** Framework supply chain security
- **Class:** CVE-backed vulnerability
- **Summary:** User-controlled structures could be interpreted as internal serialized objects during deserialization.
- **CVE:** [CVE-2025-68664](https://nvd.nist.gov/vuln/detail/CVE-2025-68664)
- **Lesson:** Framework serialization boundaries are high-risk when user data and internal object metadata overlap.

### 40. December 2025: Supply chain review of AI gateways and wrappers intensified

- **Category:** Supply chain security
- **Class:** Industry trend
- **Summary:** Organizations increasingly treated gateways, wrappers, SDKs, and orchestration layers as a full AI software supply chain requiring audit and pinning.
- **CVE:** None public
- **Lesson:** The attack surface of an LLM stack extends far beyond the model API.
