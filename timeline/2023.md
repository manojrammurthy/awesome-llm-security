# 2023 Timeline

This file includes 12 notable incidents, disclosures, and attack-research milestones relevant to LLM security in 2023.

## Entries

### 01. March 2023: ChatGPT chat history exposure

- **Category:** Data exposure
- **Class:** Public incident
- **Summary:** A bug in shared infrastructure exposed some chat titles and limited account-related metadata across users.
- **CVE:** None public
- **Lesson:** Cross-tenant bugs in session, cache, or queue layers can become immediate AI privacy incidents.

### 02. April 2023: Samsung engineers pasted source code and secrets into ChatGPT

- **Category:** Data leakage
- **Class:** Enterprise usage incident
- **Summary:** Internal users reportedly pasted sensitive code and data into an external LLM service, creating confidentiality and retention concerns.
- **CVE:** None public
- **Lesson:** LLM adoption without data handling policy quickly turns into insider-driven exfiltration risk.

### 03. May 2023: Early prompt injection against plugin-enabled assistants

- **Category:** Prompt injection
- **Class:** Public attack research
- **Summary:** Researchers showed that malicious instructions embedded in web content could steer assistants toward unsafe plugin behavior.
- **CVE:** None public
- **Lesson:** External content must never be treated as trustworthy instructions.

### 04. May 2023: Indirect prompt injection via browsed webpages

- **Category:** Indirect injection
- **Class:** Research disclosure
- **Summary:** Browsing-enabled assistants were shown to ingest attacker-controlled page content that manipulated subsequent reasoning.
- **CVE:** None public
- **Lesson:** Browsed content and retrieved context require separate trust handling from system instructions.

### 05. June 2023: System prompt extraction became a common red-team pattern

- **Category:** Prompt leakage
- **Class:** Red-team trend
- **Summary:** Public jailbreaks and extraction prompts repeatedly recovered hidden prompt fragments, policies, and formatting conventions.
- **CVE:** None public
- **Lesson:** Hidden prompts should not be treated as durable secrets.

### 06. July 2023: Plugin tool confusion attacks gained attention

- **Category:** Tool abuse
- **Class:** Research disclosure
- **Summary:** Tool-enabled assistants showed confusion between user goals, plugin descriptions, and external instructions.
- **CVE:** None public
- **Lesson:** Tool routing needs deterministic authorization rather than model judgment alone.

### 07. August 2023: RAG document injection moved from theory to practical demos

- **Category:** RAG security
- **Class:** Public attack research
- **Summary:** Adversarial instructions hidden in documents survived chunking and retrieval, then influenced assistant answers and actions.
- **CVE:** None public
- **Lesson:** Retrieval is a control boundary, not a neutral context expansion step.

### 08. August 2023: Auto-GPT style agent demos exposed unsafe autonomous behavior

- **Category:** Agent security
- **Class:** Public incident pattern
- **Summary:** Agent experiments showed how broad goals plus weak guardrails could trigger wasteful loops, unsafe plans, or risky tool proposals.
- **CVE:** None public
- **Lesson:** Planning loops and tool scopes require hard external constraints.

### 09. September 2023: Hidden instructions in PDFs and documents became an operational concern

- **Category:** Content injection
- **Class:** Research disclosure
- **Summary:** Teams recognized that uploaded documents could contain attacker-authored instructions that affected downstream LLM behavior.
- **CVE:** None public
- **Lesson:** File uploads should be treated as adversarial content, not passive knowledge.

### 10. October 2023: Promptware entered mainstream AI security discussion

- **Category:** Supply chain and content abuse
- **Class:** Conceptual milestone
- **Summary:** Security researchers framed malicious prompt-bearing content as a software-like threat class for AI systems.
- **CVE:** None public
- **Lesson:** Content can behave like code when a model is allowed to interpret it operationally.

### 11. November 2023: Early multimodal injection demos broadened the attack surface

- **Category:** Multimodal security
- **Class:** Research disclosure
- **Summary:** Researchers demonstrated that non-text inputs such as images or OCR-derived content could also carry adversarial instructions.
- **CVE:** None public
- **Lesson:** Multimodal systems inherit the same trust-boundary problem, just through more channels.

### 12. December 2023: Logging and transcript retention emerged as a major LLM privacy risk

- **Category:** Data governance
- **Class:** Operational pattern
- **Summary:** Teams found that prompts, outputs, and transcripts were often retained or copied into logs with weaker controls than source systems.
- **CVE:** None public
- **Lesson:** Derived AI artifacts should be classified and retained like the sensitive data they contain.
