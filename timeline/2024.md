# 2024 Timeline

This file includes 14 notable incidents, disclosures, and vulnerability-driven milestones relevant to LLM security in 2024.

## Entries

### 13. January 2024: LiteLLM proxy exposure and abuse discussions

- **Category:** Supply chain security
- **Class:** Deployment risk pattern
- **Summary:** Security practitioners highlighted how insecure LiteLLM proxy deployments could expose admin surfaces, provider keys, and usage controls.
- **CVE:** None public
- **Lesson:** Model gateways are high-value trust concentrators and need production-grade hardening.

### 14. February 2024: Enterprise concern around prompt leakage through model gateways

- **Category:** Gateway security
- **Class:** Operational pattern
- **Summary:** Teams increasingly recognized that AI gateways and observability middleware could capture prompts, outputs, and secrets at central choke points.
- **CVE:** None public
- **Lesson:** Logging and proxy layers are sensitive systems, not passive plumbing.

### 15. March 2024: Claude command bypass reports

- **Category:** Command generation and policy bypass
- **Class:** Public attack pattern
- **Summary:** Tool-enabled assistant workflows were pushed into producing or reformatting dangerous commands despite higher-level safety intent.
- **CVE:** None public
- **Lesson:** Command safety must be enforced outside the model.

### 16. March 2024: Ollama DNS rebinding issue disclosed

- **Category:** Local model serving security
- **Class:** CVE-backed vulnerability
- **Summary:** Local Ollama deployments exposed on localhost were shown to be vulnerable to DNS rebinding-driven abuse in some setups.
- **CVE:** [CVE-2024-28224](https://nvd.nist.gov/vuln/detail/CVE-2024-28224)
- **Lesson:** Local-only trust assumptions fail when browsers and web origins can pivot into local services.

### 17. April 2024: RAG poisoning in internal knowledge bases became a repeatable red-team finding

- **Category:** RAG poisoning
- **Class:** Enterprise attack pattern
- **Summary:** Red teams found that seeded documents could bias enterprise assistants toward manipulated outputs or risky actions.
- **CVE:** None public
- **Lesson:** Corpus integrity matters as much as model safety.

### 18. May 2024: Langflow custom component remote code execution exposure

- **Category:** Agent framework security
- **Class:** CVE-backed vulnerability
- **Summary:** Langflow deployments allowing unsafe custom component execution highlighted the risk of code paths hidden behind low-friction AI workflow builders.
- **CVE:** [CVE-2024-37014](https://nvd.nist.gov/vuln/detail/CVE-2024-37014)
- **Lesson:** Low-code AI platforms are still code-execution platforms.

### 19. June 2024: RoguePilot disclosure

- **Category:** Agent security
- **Class:** Public attack case
- **Summary:** RoguePilot focused attention on agent takeover paths where untrusted context, broad goals, and powerful tools combined into unsafe autonomy.
- **CVE:** None public
- **Lesson:** Agents need explicit approval and policy boundaries between planning and acting.

### 20. July 2024: Langflow mass-assignment and auth-related concerns surfaced

- **Category:** Platform abuse
- **Class:** CVE-backed vulnerability
- **Summary:** Weak control paths in AI workflow platforms showed how application-level issues could compromise LLM infrastructure and user data.
- **CVE:** [CVE-2024-7297](https://nvd.nist.gov/vuln/detail/CVE-2024-7297)
- **Lesson:** Standard web app classes still apply directly to AI platforms.

### 21. August 2024: Tool-calling copilots were shown to over-trust generated shell and API actions

- **Category:** Agent tool abuse
- **Class:** Research trend
- **Summary:** Red-team work repeatedly showed that assistants would escalate harmless user requests into risky command or API suggestions when tools were loosely constrained.
- **CVE:** None public
- **Lesson:** Tool schemas and policy validation are mandatory.

### 22. September 2024: Ollama path traversal and file handling issues gained attention

- **Category:** Local inference stack security
- **Class:** CVE-backed vulnerability
- **Summary:** Multiple Ollama disclosures demonstrated unsafe file and model handling paths in self-hosted model serving workflows.
- **CVE:** [CVE-2024-39719](https://nvd.nist.gov/vuln/detail/CVE-2024-39719), [CVE-2024-39720](https://nvd.nist.gov/vuln/detail/CVE-2024-39720), [CVE-2024-39722](https://nvd.nist.gov/vuln/detail/CVE-2024-39722)
- **Lesson:** Self-hosted AI tools need the same file-system and input validation rigor as any network service.

### 23. October 2024: Langflow Python tool execution issues expanded the agent risk model

- **Category:** Tool execution security
- **Class:** CVE-backed vulnerability
- **Summary:** Unsafe code execution paths in workflow tooling highlighted how agent features can collapse directly into remote code execution risks.
- **CVE:** [CVE-2024-42835](https://nvd.nist.gov/vuln/detail/CVE-2024-42835)
- **Lesson:** Tool execution should run in isolated sandboxes with explicit allowlists.

### 24. October 2024: Ollama archive extraction issues reinforced model artifact trust problems

- **Category:** Supply chain and artifact handling
- **Class:** CVE-backed vulnerability
- **Summary:** Archive extraction and packaging flaws showed that model pulls and artifact handling can become a compromise path.
- **CVE:** [CVE-2024-45436](https://nvd.nist.gov/vuln/detail/CVE-2024-45436)
- **Lesson:** Model files should be treated as untrusted content until validated.

### 25. November 2024: Whisper-related transcription leakage concerns

- **Category:** Multimodal security
- **Class:** Operational incident pattern
- **Summary:** Teams raised concerns that transcripts, summaries, and related logs often inherited weaker controls than the original audio data.
- **CVE:** None public
- **Lesson:** Derived multimodal artifacts are sensitive data and need full lifecycle controls.

### 26. December 2024: Unsandboxed AI workflow components remained a recurring deployment weakness

- **Category:** AI platform hardening
- **Class:** CVE-backed vulnerability class
- **Summary:** Additional Langflow disclosures reinforced that self-hosted AI workflow tools can expose unsandboxed code execution and weak multi-user isolation.
- **CVE:** [CVE-2024-48061](https://nvd.nist.gov/vuln/detail/CVE-2024-48061)
- **Lesson:** Self-hosted AI orchestration should start from zero trust, not localhost trust.
